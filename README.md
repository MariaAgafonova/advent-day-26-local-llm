# День 26. Запуск локальной LLM

Небольшое приложение на Python и HTML/JS обращается к локальной модели через HTTP API Ollama.
Есть веб-интерфейс, запуск одиночного запроса из CLI и воспроизводимая проверка трёх задач разной сложности.
Нужен **Python 3.10+**, сторонние Python-пакеты, Node.js и API-ключи для запуска не требуются.

## Запуск приложения

Ollama должна быть запущена. На этом компьютере она установлена в `F:\LocalLLM\Ollama`,
а модели хранятся в `F:\LocalLLM\models`.
Обнаружены `qwen3.5:4b` (4.2B, около 3.3 ГБ) и `qwen3.5:latest` (9B, около 6.6 ГБ).
По умолчанию выбрана модель 4B; другую установленную модель можно выбрать в интерфейсе.

В PowerShell:

```powershell
cd D:\AIAdvent\advent-day-26-local-llm
python app.py
```

Откройте **http://127.0.0.1:8526**. Альтернативный запуск: `./start.ps1`.
Остановка сервера — `Ctrl+C` в его терминале. Другой порт: `python app.py --port 8527`.

Введите запрос и нажмите «Отправить запрос» или `Ctrl+Enter`.
Карточки примеров подставляют текст в поле. Кнопка «Запустить все три» последовательно отправляет
простой, средний и сложный запросы. Для каждого ответа отображаются время, токены и скорость генерации.
Кнопка «Скачать JSON» сохраняет ответы текущей страницы. После обновления страницы история очищается.
Каждый запрос независимый: предыдущие ответы не передаются в контекст.

Первый запрос может занимать около минуты из-за загрузки модели. Тайм-аут генерации — 300 секунд,
контекст — 4096 токенов, максимум ответа — 1024 токена, `temperature=0.2`, `think=false`.
Если ответ достиг лимита, интерфейс показывает предупреждение. Модель остаётся в памяти 30 минут
после обращения. Крупная модель может потребовать больше памяти и времени.

## Как вызвать модель из CLI

Через приложение (использует тот же HTTP-клиент):

```powershell
python app.py --ask "Как называется столица Сербии?"
python app.py --model qwen3.5:latest --ask "Объясни, что такое локальная LLM."
```

Напрямую через Ollama:

```powershell
& "F:\LocalLLM\Ollama\ollama.exe" list
& "F:\LocalLLM\Ollama\ollama.exe" run qwen3.5:4b "Сколько будет 2 + 2?"
& "F:\LocalLLM\Ollama\ollama.exe" ps
```

Для интерактивного диалога: `ollama run qwen3.5:4b`; выход — `/bye`.

## Прямой HTTP-запрос

```powershell
$payload = @{
    model = 'qwen3.5:4b'
    messages = @(@{ role = 'user'; content = 'Как называется столица Сербии?' })
    stream = $false
    think = $false
} | ConvertTo-Json -Depth 5
$response = Invoke-RestMethod -Uri 'http://127.0.0.1:11434/api/chat' `
    -Method Post -ContentType 'application/json; charset=utf-8' `
    -Body ([System.Text.Encoding]::UTF8.GetBytes($payload)) -TimeoutSec 300
$response.message.content
```

## Три запроса и отчёт

При работающем `python app.py` откройте второй терминал в папке проекта:

```powershell
python verify.py
```

Проверка отправляет три **реальных** запроса через сервер приложения:

1. Простой: столица Сербии, одно предложение.
2. Средний: стоимость покупки, скидка 15%, итог и сдача.
3. Сложный: функция объединения интервалов, граничные случаи и оценка сложности.

Результаты: [DAY26_RESULTS.md](DAY26_RESULTS.md) и [output/day26-results.json](output/day26-results.json).
Повторный запуск обновляет эти файлы. JSON содержит исходные ответы Ollama и список моделей в памяти.
Проверка подтверждает непустые завершённые ответы, отсутствие обрезания и наличие модели в `/api/ps`.
Она не доказывает смысловую корректность произвольного ответа и не исполняет сгенерированный код.

Автоматические проверки обработки ошибок и HTTP API, без модели и интернета:

```powershell
python -B -m unittest discover -s tests -v
```

## Если Ollama недоступна

Запустите приложение Ollama из меню Windows. Если нужен ручной сервер, в отдельном PowerShell:

```powershell
$env:OLLAMA_MODELS = 'F:\LocalLLM\models'
& 'F:\LocalLLM\Ollama\ollama.exe' serve
```

Если порт 11434 уже занят Ollama, второй сервер запускать не нужно. Нажмите «Проверить соединение»
в интерфейсе. Список установленных моделей доступен по `http://127.0.0.1:11434/api/tags`.

## Как устроено

```text
Браузер → Python (127.0.0.1:8526) → Ollama (127.0.0.1:11434) → локальная Qwen
```

- `app.py` — HTTP-сервер на loopback и CLI.
- `ollama_client.py` — вызовы Ollama, параметры генерации, три примера.
- `static/` — интерфейс без внешних CDN и библиотек.
- `verify.py` — проверка на реальной модели и сохранение отчёта.
- `tests/` — проверка отказов и валидации запросов.

Адрес Ollama фиксирован на loopback; прокси для запросов отключены. Приложение не отправляет
запросы облачным провайдерам и не требует доступа в интернет при работе с установленными моделями.
В интерфейсе показываются локальные модели, облачные псевдонимы с `remote_host` отфильтрованы.

Документация: [Ollama Chat API](https://docs.ollama.com/api/chat),
[список моделей](https://docs.ollama.com/api/tags), [управление thinking](https://docs.ollama.com/capabilities/thinking).
