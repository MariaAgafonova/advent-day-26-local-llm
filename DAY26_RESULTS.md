## 2. Средний: Задача в несколько шагов

**Запрос**

В магазине 3 блокнота по 240 рублей и 2 ручки по 80 рублей. На всю покупку действует скидка 15%. Покупатель дал 1000 рублей. Рассчитай стоимость до скидки, сумму скидки, итоговую стоимость и сдачу. Покажи вычисления кратко.

**Ответ модели (без редактирования)**

Вот расчеты:

1.  **Стоимость до скидки:**
    *   Блокноты: $3 \times 240 = 720$ руб.
    *   Ручки: $2 \times 80 = 160$ руб.
    *   Итого: $720 + 160 = 880$ руб.

2.  **Сумма скидки:**
    *   $880 \times 0,15 = 132$ руб.

3.  **Итоговая стоимость:**
    *   $880 - 132 = 748$ руб. (или $880 \times 0,85 = 748$ руб.)

4.  **Сдача:**
    *   $1000 - 748 = 252$ руб.

**Ответ:** Сдача составляет **252 рубля**.

## 3. Сложный: Код и граничные случаи

**Запрос**

Напиши на Python функцию merge_intervals(intervals), которая объединяет пересекающиеся и соприкасающиеся закрытые интервалы. Вход — список пар целых чисел [start, end], где start <= end. Не изменяй исходный список. Обработай пустой список. Для [[1,3],[2,6],[8,10],[10,12]] результат должен быть [[1,6],[8,12]]. Дай код функции, 3 assert-проверки (обычный случай, пустой список, вложенные интервалы) и кратко оцени сложность. До 250 слов.

**Ответ модели (без редактирования)**

```python
def merge_intervals(intervals):
    if not intervals:
        return []

    # Создаем копию списка для неизменения исходных данных
    sorted_intervals = sorted(intervals, key=lambda x: x[0])
    merged = [sorted_intervals[0]]

    for current in sorted_intervals[1:]:
        last = merged[-1]
        if current[0] <= last[1]:
            # Пересекаются или соприкасаются: объединяем
            merged[-1] = (last[0], max(last[1], current[1]))
        else:
            # Не пересекаются: добавляем новый интервал
            merged.append(current)

    return merged

# Проверки
assert merge_intervals([[1,3],[2,6],[8,10],[10,12]]) == [[1,6],[8,12]]
assert merge_intervals([]) == []
assert merge_intervals([[1,4],[2,5],[3,6]]) == [[1,6]]

# Сложность: O(n log n) из-за сортировки. Пройденный цикл O(n).
```
